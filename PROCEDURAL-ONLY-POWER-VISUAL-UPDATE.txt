PUNJABI GAME ARENA — PROCEDURAL-ONLY POWER VISUAL UPDATE

This update addresses the screenshot feedback: the previous centre collision looked like a pale blue/white blob and the power projectile visuals were being drawn from PNG textures. The current combat component now renders powers procedurally with Canvas 2D only.

Changes:
- Removed all power-effect PNG texture preloading and cache references from SuperheroClash.
- Removed all image drawImage calls from the live combat renderer.
- Replaced the old PNG texture renderer with a procedural attack renderer that draws animated power silhouettes.
- Moved charge origins to the upper-left and upper-right fighter hand/upper-body zones.
- Moved the collision point into the upper-middle of the arena.
- Moved the final impact target to the opponent's upper body.
- Enlarged the live power silhouettes during release so the attack type is easier to identify.
- Added dedicated plasma orb visuals with a hot core and rotating ion bands.
- Kept distinct procedural visuals for fire, lightning, ice, water, shadow, solar, shield, healing, wind, impact and speed.
- Improved the collision with multiple expanding energy rings and live particle bursts.
- Reduced the oversized white impact bloom so it does not wash out the entire collision.
- Preserved the existing fighters, fighter action sprites, arena background, turn selection, power selection, attack button, health/damage logic, rounds and winner flow.

No PNG/SVG power effect is loaded or rendered by the combat component. The character sprites remain the existing project artwork, as requested.

Validation:
- TypeScript TSX transpilation: 0 diagnostics.
- CSS parser: passed.
- Source scan: no power-effects image path references in src code.
- Source scan: no drawImage calls in SuperheroClash.tsx.

Limitations:
- A complete Vite production build and live browser/device frame-rate benchmark were not performed in this environment. The package should be deployed to Netlify and checked in the actual browser before claiming measured performance.
